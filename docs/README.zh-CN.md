## 核对记录归档

[verification/](verification/) 按版本保存历史核对证据，不代表当前源码重新通过了其中的检查。报告原文和哈希保持不变；归档 JSON 中的路径可能指向当时的本地研究环境。发布说明保留原版本标签的上下文。

原 `audit/<版本>/` 已归入 `docs/verification/<版本>/`。原根目录 `validation-pack.json` 属于 v1.0.3；`validation-toolbar-<版本>.json` 现位于 `docs/verification/<版本>/validation-toolbar.json`。[file-provenance.json](../file-provenance.json) 和 [sources/](../sources/) 继续保存资源来源记录。[pack/CREDITS.txt](../pack/CREDITS.txt) 是唯一维护的完整署名文件。早期文档提到的 `inspection/`、研究用 JAR 或完整来源快照属于当时的本地工作文件，不是本仓库打包所需文件。
