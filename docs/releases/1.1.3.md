## Installation / 安装

For Minecraft **1.20.1**, paired with **AE2 Light UI Compat 1.1.3** on Forge. Enable the attached ZIP in `resourcepacks`, disable older merged packs and overlapping source packs, replace the companion JAR, and restart the client.

适用于 Minecraft **1.20.1**，在 Forge 环境下搭配 **AE2 Light UI Compat 1.1.3**。将附件 ZIP 放入 `resourcepacks` 并启用，停用旧版合并包及重复来源包，同时替换适配模组 JAR 并重启客户端。
