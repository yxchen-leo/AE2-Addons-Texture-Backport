# v1.2.8

## Changes / 更新内容

- Remove one unused language-download cache file (`zh_cn.etag`) and update the provenance inventory. Retained textures, models, layouts, translations, credits and licenses keep their original bytes; pack metadata now identifies v1.2.8.
- 删除一个无用语言下载缓存并同步来源清单。保留的材质、模型、界面布局、翻译、署名及许可字节不变，资源包元数据更新为 v1.2.8。
- Add `python package.py --check` for inventory, SHA-256, resource paths, JSON duplicate keys and PNG integrity. Packaging verifies a temporary ZIP before replacing the output; `--output` allows isolated verification builds.
- 新增完整性检查入口，核对清单、哈希、路径、JSON 重复键及 PNG；打包通过临时 ZIP 校验后才替换目标，支持指定核对产物位置。
- Consolidate ignore rules and bilingual maintenance documentation. See the [integrity review](https://github.com/yxchen-leo/AE2-Addons-Texture-Backport/blob/v1.2.8/docs/project-integrity.md) for reference classifications and remaining limits.
- 整理忽略规则和中英文维护文档；引用分类与边界见完整性核对报告。

## Installation / 安装

Minecraft **1.20.1 / Forge**. Put the ZIP in `resourcepacks`, disable older merged packs and enable this version. Pair it with [AE2 Light UI Compat v1.2.8](https://github.com/yxchen-leo/AE2-Light-UI-Compat/releases/tag/v1.2.8), remove the old companion JAR and restart Minecraft. The fixed in-game display name remains **AE2 & Addons Texture Backport**.

将 ZIP 放入资源包目录，停用旧版并启用新版，配合 v1.2.8 适配模组，移除旧 JAR 后重启。游戏内名称保持 **AE2 & Addons Texture Backport**。本包不新增物品或方块，不单独提供服务端战利品修复。

核对 **4,467 个文件、2,495 份 JSON/元数据、1,965 张 PNG 和 363 条界面 include**；检查来源哈希、模组/Forge 引用及 ZIP 与源码一致性。错误样本确认校验失败不会覆盖原产物。未启动游戏；实例未安装的可选附属仍有核对边界，素材继续遵循原许可。
