## Installation / 安装

For Minecraft **1.20.1**, paired with **AE2 Light UI Compat 1.1.2** on Forge. Enable the attached ZIP in `resourcepacks`, disable older merged packs and overlapping source packs, replace the companion JAR, and restart the client.

适用于 Minecraft **1.20.1**，在 Forge 环境下搭配 **AE2 Light UI Compat 1.1.2**。将附件 ZIP 放入 `resourcepacks` 并启用，停用旧版合并包及重复来源包，同时替换适配模组 JAR 并重启客户端。

## Changes / 更新内容

- Adds a dedicated modern tab atlas, copied byte-for-byte from AE2 1.21.1. Companion mod 1.1.2 uses it for back/priority icons and tab rendering without replacing the legacy icon atlas.
- Aligns the wireless trash back button to `(152, -5, 20, 20)` and adds a wireless settings layout override with the back button at `(176, -5, 20, 20)`.
- Updates credits and file provenance, and includes a full resource inventory, upstream comparisons and addon support report.

- 加入专用高版本页签图集，按原字节复制 AE2 1.21.1 资源；适配模组 1.1.2 用它绘制返回/优先级图标及页签，保留旧图标图集。
- 将无线垃圾桶返回按钮对齐到 `(152, -5, 20, 20)`，新增无线设置页布局覆盖，返回按钮位置为 `(176, -5, 20, 20)`。
- 更新署名和逐文件来源，附带完整资源清单、上游对照与附属支持报告。

## Verification and scope / 验证与范围

Inventoried **4,988 files**, including 2,070 PNGs and 2,444 JSON/metadata files. File parsing, provenance hashes, animation-frame bounds and ZIP contents were checked. **No in-game visual verification was performed.**

This is not a complete backport of every modern resource or addon GUI. The audit records 83 same-path PNGs with visible differences, uncovered upstream resources, and five legacy namespaces without a verified modern reference. Addon button compatibility does not imply complete asset coverage. See the [full audit and support table](https://github.com/yxchen-leo/AE2-Addons-Texture-Backport/blob/v1.1.2/docs/1.1.2-%E5%AE%8C%E6%95%B4%E6%A0%B8%E5%AF%B9.md).

已清点 **4,988 个文件**，包括 2,070 张 PNG 和 2,444 份 JSON/元数据，并检查文件解析、来源哈希、动画帧范围与 ZIP 内容。**尚未进行游戏内画面验收。**

当前没有完整移植所有高版本资源或附属 GUI。报告列明 83 张存在可见差异的同路径 PNG、未覆盖的上游资源，以及 5 个尚无可核验高版本参照的遗留命名空间。按钮适配不等于整个附属材质已经移植，详情见上述完整核对报告与支持表。
