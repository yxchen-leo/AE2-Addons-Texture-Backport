# AE2 合并材质包 v1.0.2 全量核对报告

核对日期：2026-10-16。**结论：不能称为所有资源都与高版本完全一致。** 已完成当前包全部资源文件的静态清点及可取得高版本资源的逐文件比较，并修正本轮确认的遗漏。保留的跨版本适配、原包重绘和未完成对应验证的资源均在下文列明。

最终成品：`AE2-Addons-Texture-Backport-1.20.1-v1.0.2.zip`，4,984 个文件，其中 2,067 张 PNG（含 pack.png）、2,443 份 JSON/元数据。SHA-256：`298d4e8939fb19677dd9e6d0772ee926569adaadb1b6ac57aeb08866e223f78a`。

## 本轮已落实的修正

- **101 张 PNG 对齐实际高版本 JAR**：6 张 AE2 处理器/压印模板图片；27 张此前未覆盖、而旧版模型实际使用的图片；48 张物品图片；20 张模型几何与贴图引用一致的方块/部件图片。这里按文件计数，重新编码但像素原已相同的文件也计入，不代表 101 个不同物品都发生肉眼可见变化。
- 补齐的内容包括 AdvancedAE 高级 IO 总线与量子合成终端、AE2 Crystal Science 镜像样板供应器与连接水晶系列、ExtendedAE Plus 的部分方块与物品。
- 校正了 AE Additions 存储元件、晶体科学处理器与接口升级、网络分析器、Applied Flux 百万级能源元件，以及部分其他附属的重绘配色。
- 为 AE2 的 1k/4k/16k/64k/256k 和 MEGA 的 1m/4m/16m/64m/256m 静态存储灯图片新增 **10 份空动画元数据**，阻止继承旧 JAR 的多帧配置。此前只检查包内显式元数据，漏掉了这种继承问题。
- 修正 **12 个模型文件**的未定义贴图变量：3 个石英灯模型、AppliedE EMC 模块，以及部分 AdvancedAE/AppBot/ExtendedAE 模型。只补上已有材质的引用，保留几何和 UV；部分原问题位于隐藏面或零面积面，不将它们全部描述为肉眼可见故障。

## 你特别要求保留的效果

- 量子结构玻璃**物品栏模型**仍使用 AdvancedAE 1.6.11 / Minecraft 1.21.1 的透明立方体与独立贴图路径，已从最终 ZIP 解析模型并校验实际引用。
- MEGA 累积处理器、印刷电路板和压印模板仍与 MEGA Cells 4.11.0 的实际物品图片一致。
- 370 个 GUI/屏幕布局文件与之前版本逐字节一致；17 个量子计算机世界贴图/动画文件与之前版本逐字节一致。
- 无任何 `assets/minecraft/textures/` 覆盖。原版物品栏、菜单及通用按钮隔离方案保留，按钮适配 JAR 无需更新。

## 验证与边界

- 最终 ZIP 的 101 张本轮更改图片，直接与来源 JAR 再次逐字节比较通过，不仅与中间快照比较。
- 将资源包叠加到已取得的 1.20.1 原版及附属基准后，检查了 5,643 个有效模型（含原版和基准模组模型），未发现新增的未解析模型引用；动画帧越界为零。此结果仅覆盖已取得基准的命名空间。
- AE2 父模板中的 `_bright_`/`_medium_`/`_dark_`/`_type_` 由具体子模型覆盖，已检查子模型继承后的引用；不将模板占位值误报为丢失图片。
- AE2 177 份屏幕样式和 163 处贴图区域检查通过。按钮适配逻辑未变化，模组已更名为 AE2 Light UI Compat；更名后重新执行真实 Mixin 离线验证。
- 包中 4 个含空格/大写等非法资源路径的源包遗留文件没有任何 JSON 模型引用，不应将它们计为成功移植的游戏资源；详情在 `unused-invalid-paths.json`。
- **未启动 Minecraft 实测**。无法据此保证所有光影、渲染器、模组版本组合都与高版本视觉完全一致。取得的 1.20.1 参照版本也不等同于已经确认了用户整合包的全部实际版本。

缺少 1.20.1 运行基准的命名空间：`ae2_mega_things`, `ae2insertexportcard`, `ae2netanalyser`, `ae2things`, `ae2wtlib`, `appelem`, `arseng`, `expatternprovider`, `gregiceng`, `infinitycells`, `mae2`, `mae2a`。

## 可复核文件

- `comparison.json`：包内全部资源逐文件分类，包括模型、GUI、语言/辅助资源；不是只抽查几个物品。
- `png-pixels-v1.0.2.json`：同路径 PNG 字节不同时的逐像素比较，透明区域的不可见 RGB 差异不算可见差异。
- `reference-sources.json` / `reference-owners.json`：每个参照 JAR 的版本、路径、哈希以及文件归属。
- `compatibility-v1.0.2.json`：旧版基准、有效模型、动画继承和检查边界。
- `verified-fixes-v1.0.2.json`：本轮修正与保护项验证。
- 项目 `sources/audit-fixes/manifest.json`：101 张上游图片的来源及哈希；`sources/items-1.21.1/manifest.json`：玻璃与 MEGA 原修正来源。

补充取得的官方发布来源：[AE2 MEGA Things 2.0.4](https://www.curseforge.com/minecraft/mc-mods/ae2-mega-things/files/6203833)、[AE2 Things 1.4.2-beta](https://www.curseforge.com/minecraft/mc-mods/ae2-things-forge/files/5637783)。其他官方 Modrinth 下载 URL 与校验值保存在 `sources/audit-extra/manifest.json` 及 `baseline-downloads.json`。

## 使用此版本

启用 `AE2-Addons-Texture-Backport-1.20.1-v1.0.2.zip`，停用 v1.0.0/v1.0.1 和两个原资源包。已安装的 `AE2-Light-UI-Compat-Forge-1.20.1-v1.0.0.jar` 继续使用。旧 ZIP 保留用于回退。
