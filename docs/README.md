## Verification archive

Reports in [verification/](verification/) are historical evidence for the version in each folder, not a fresh verification of the current source. Original report contents and hashes are preserved. Paths inside archived JSON may refer to the original local research environment. Release notes retain their original tag context.

The former `audit/<version>/` directory is now `docs/verification/<version>/`. Root `validation-pack.json` belongs to v1.0.3; `validation-toolbar-<version>.json` is now `docs/verification/<version>/validation-toolbar.json`. [file-provenance.json](../file-provenance.json) and [sources/](../sources/) remain the resource provenance records. [pack/CREDITS.txt](../pack/CREDITS.txt) is the canonical attribution file. Older mentions of `inspection/`, research fixtures or full source snapshots describe local working files, not files required to package this repository.
