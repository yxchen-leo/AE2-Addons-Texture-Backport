# 1.1.0 左侧工具栏移植

适配模组和资源包均升级为 1.1.0，适用于 Minecraft 1.20.1 / Forge。

## 安装

1. 用 `AE2-Light-UI-Compat-Forge-1.20.1-1.1.0.jar` 替换旧适配模组。
2. 启用 `AE2-Addons-Texture-Backport-1.20.1-v1.1.0.zip`，停用旧版合并包及来源包，避免覆盖。
3. 重启客户端。仅调整资源包时，可用 F3+T 重载；更新 JAR 需要重启。

## 改动

- `VerticalButtonBar` 新增连续背景绘制，根据可见按钮实时计算高度。
- 使用上边 2 像素、下边 4 像素的分段绘制，中段重复，保留边框厚度。
- 侧栏按钮间隔由 4 改为 6，公共侧栏坐标由 `(0,1)` 改为 `(3,1)`；底板与主面板重叠 2 个 GUI 像素。
- 普通侧栏图标按钮使用 18×20 背景，支持普通、焦点、悬停三种状态；悬停下移 1 像素。
- 底板、按钮、图标分层绘制。原图标来源和按钮功能保留，沿用高版本的 16×16 点击区域。
- 半尺寸图标按钮保留原渲染；继承 AE2 图标按钮并注册进工具栏的附属控件可以沿用适配，独立自绘控件不保证覆盖。
- 新侧栏贴图缺失时恢复旧间隔和绘制；原来的优先级等文字按钮适配仍然保留。

资源来自 AE2 1.21.1 官方提交 `db17504a86128fdf3dae31f5fb7a112a646e0b93`。贴图按原字节复制到专用命名空间，未覆盖旧版 `states.png`，以保留 1.20.1 的图标坐标。来源与哈希见 `sources/toolbar-1.21.1/manifest.json`，署名与许可见 `CREDITS.txt`。
