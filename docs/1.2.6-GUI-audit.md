# 1.2.6 GUI 与 ExtendedAE 物品核对

参照为实例中的 AE2 15.4.11、ExtendedAE 1.4.21、AE2LT 2.1.2-beta2 等，以及本地保存的 AE2 19.2.18、ExtendedAE 1.21.1 源码、AE2LT beta3、AE2CS 1.2.1。此次是静态代码、资源及布局核对，未启动游戏。文件清单见 `audit/1.2.6/installed-screen-inventory.json`。

## 已确认并修复

| 项目 | 原因 | 处理 |
| --- | --- | --- |
| ExtendedAE 无线扩展合成终端物品图标 | 缺失 `wireless_ex_ct` 模型/贴图覆盖，仍加载模组旧图标 | 复用包内现代无线合成终端贴图，补上独立模型及资源路径 |
| 中文缺失 | 原模组缺 13 条，启用资源包后仍缺 7 条 | 保留已有翻译，补齐物品、快捷键、精确输出和无线连接提示；保留格式参数与颜色码 |
| 槽位悬停 | 仍为白色填充 | 移植浅蓝填充和边框，保留可变槽位尺寸及旧引擎层级 |
| 禁用可选槽位 | 旧透明度为 0.4 | 配套资源包启用时改为高版本的 0.2 |
| 右侧工具箱 | common/toolbox.json 未覆盖，旧裁切/槽位位置与新风格不一致 | 采用高版本布局和独立原图；既有左侧工具箱不共用新图集 |
| AE2LT 机器界面 | 部分仍引用 legacy 玩家物品栏或旧能量条 | 逐字段适配物品栏、能量条；保留旧版菜单字段 |
| AE2LT 输出面配置 | 4 个页面的清除按钮位置旧 | 移到高版本位置，保留方向按钮旧 API 所需的尺寸 |
| AE2LT 过载接口、IO 端口、种子储存、Pigmee 合成站 | 背景引用/裁切高度、过滤按钮、标题位置遗漏 | 采用对应高版本可兼容的外观字段 |
| AE2LT 合成确认 | 新背景 238×260；旧代码仍按 256×256 图集和 68px 页脚裁切 | 独立新背景及布局；代码改为 64px 页脚、56px 主切片、252px 底边起点 |
| AE2CS 简易样板供应器 | 仍引用旧的附属物品栏布局 | 改用高版本 common/player_inventory |
| ExpandedAE IO 端口 | 旧背景裁切高 166，新图为 168 | 修正为 168，保留旧版槽位与操作控件定义 |

无线扩展合成终端在本轮核对的 ExtendedAE 1.21.1 源码中没有同名物品，因此其图标是现代风格适配，不能称为该物品的高版本原图。它与普通无线合成终端复用图案，通过物品名称区分。

## 覆盖范围与剩余差异

- 审核清单包含 AE2、AE2WTLib、ExtendedAE、ExpandedAE、AdvancedAE、水晶科技、闪电科技、MEGA Cells、ME Requester、Applied Mekanistics、ae2CraftingTree 和本地 ae2lab 的屏幕资源。未被资源包覆盖的 JSON 不等于错误：很多页面继承已适配的公共布局，或与参照一致。
- 通用按钮、侧栏、页签、复选框、滚动条和槽位外观适用于调用 AE2 对应路径的页面。附属完全自绘的列表/图表不自动等同于高版本实现。
- AE2 高版本数量输入的 Shift/Ctrl 步长切换、天枢新增模式及面板属于交互/菜单功能，仍使用旧版本逻辑。
- 天枢多处 helpTopic 指向高版本新增手册页面，本次保留旧值，避免再次引入不存在的 GuideME 页面。
- 天枢无线终端的高版本布局依赖新的 AE2WTLib universal_terminal.json；1.20.1 保留有视图元件的旧兼容入口。
- 高版本新增工具箱涉及菜单支持时，仅更新已有工具箱的公共外观，不凭空增加旧菜单没有的槽位。
- `void_cell.json` 在不同附属中存在同路径资源，跨模组文件名相同不能作为直接替换依据；本次保留实际安装版本的入口和翻译键。
- 未进行所有页面的游戏内运行验收，不能把本轮结果描述为全部高版本功能和界面的完整移植。

## 安装

同时使用适配模组 v1.2.6 与资源包 v1.2.6。资源包新增的闪电科技合成确认背景依赖配套代码裁切，不建议与旧 JAR 混用。核对与构建阶段未修改游戏实例或存档。

## AE2 Lab 0.1.4 补充核对（2026-10-28）

当前 AE2 Lab 0.1.4 已将物品、方块注册 ID 和相关模型/贴图迁移到 `expatternprovider`，此前 0.1.3 使用 `ae2lab` 的结论不再适用。与实例启用的资源包 v1.2.4 存在 69 个同路径资源，其中 25 张贴图内容相同。同路径模型/贴图按资源优先级覆盖，不会因此重复绘制物品；语言文件按键合并。此次发布未修改 AE2 Lab 的注册或迁移代码。
