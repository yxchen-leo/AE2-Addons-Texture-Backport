# 1.1.2 全量资源与附属支持核对

日期：2026-10-18。**当前资源包没有完整移植高版本 AE2 及所有附属的全部资源，适配模组也不是整个高版本 GUI 框架的移植。** 本轮按文件检查整个包，并反向检查上游存在而包内没有覆盖的路径。确认的返回图标和无线终端定位问题已修复为 1.1.2。

## 核对口径

低版本优先使用用户实际 1.20.1 实例的 JAR；未安装的附属使用下载到研究目录的 Forge 参照。高版本使用本地 ATM10 的实际 JAR，并以本次取得的官方 1.21.1 发布文件补齐或更新参照。完整文件名、SHA-256 和下载来源见 `audit/1.1.2/references.json`、`download-sources.json`。没有把所有 1.21.1 以后的版本视为同一套资源。

AE2 主参照为 19.2.18；源码 GUI 对比固定于 `db17504a86128fdf3dae31f5fb7a112a646e0b93`。附属包括 AE2WTLib 19.5.1、AdvancedAE 1.6.12、ExtendedAE 2.2.33、MEGA Cells 4.11.0、水晶科技 1.2.1、闪电科技 2.1.2-beta3、ME Requester 1.5.0、Applied Flux 2.1.5 等。源码参照和发布 JAR 分开记录。

高版本命名空间 `extendedae` 映射为旧版 `expatternprovider`，`ae2importexportcard` 映射为 `ae2insertexportcard`。新导航图集和工具栏图集按实际来源对应到高版本 `states.png`。其他改名资源列为未找到同路径，不能据此认定丢失或已成功移植。

## 本轮修复

- 配套适配模组识别返回按钮语义，绘制高版本返回箭头，覆盖 ME 驱动器优先级、无线垃圾桶、无线设置、终端设置及使用相同路径的附属页面。
- 新增专用 `tab_buttons.png`，按原字节复制高版本图集。其他物品/模式页签保留原有图标；修正页签背景、焦点状态与图标偏移，并适配优先级入口图标。
- 无线垃圾桶返回按钮改为 `(152,-5,20,20)`；无线设置页新增布局覆盖，返回按钮改为 `(176,-5,20,20)`。磁铁页定位已经对应高版本，无需更改。
- 更新逐文件来源清单，补齐原先未登记的 pack 元数据和许可证文件；原资源内容未因此重写。保留已有量子结构玻璃、物品材质等选择。
- 详细代码差异与已确认的附属调用路径见适配模组的 `docs/1.1.2-GUI-audit.md`。

## 全量结果

包内共 **4,988 个文件**，其中资源目录文件 4,983 个；PNG 共 2,070 张，JSON/元数据 2,444 份。包含 AE2 与附属的 28 个资源命名空间，另有适配模组命名空间及一份 Minecraft 图集声明。后者没有替换原版 GUI 贴图。

| 分类 | 文件数 | 含义 |
| --- | ---: | --- |
| 与参照字节一致 | 3746 | 包含明确的专用图集路径映射 |
| 仅 PNG 编码/不可见 RGB 不同 | 15 | 解码后的可见像素一致 |
| 仅 JSON 序列化不同 | 187 | 解析后的数据一致 |
| 同路径内容不同 | 613 | 包括旧格式适配、原包设计、新版变化和未处理差异 |
| 未找到高版本对应路径 | 352 | 包含改名、旧版独有和本地适配，尚不能一概判为缺失 |
| 该命名空间无可核对高版本参照 | 70 | 保留现有资源，不宣称来自高版本 |
| 根目录/许可元数据 | 5 | 不计入模组同路径资源比较 |

同路径内容不同的文件中，**83 张 PNG 存在可见像素或尺寸差异**。这包括 GUI、既有配色、世界材质和模型配套贴图，不能把它们全部称为必要兼容修改，也不能把它们全部直接覆盖为上游图。逐文件路径在 `files.json`，没有把抽样结果当作全量结果。

反向核对发现：

- **297** 个：旧版基准已有、与高版本内容不同、包中没有覆盖。
- **1393** 个：包中未覆盖，但旧版与高版本内容等价。
- **827** 个：高版本路径存在，已取得旧版基准中没有同路径。

这些统计包括语言、模型、指南图片和新增内容，不能将 297 个差异路径等同于 297 个游戏内贴图缺失，也不能将 827 个新路径等同于 827 个可直接移植的资源。37 个未覆盖变化路径属于屏幕布局或 GUI 贴图，主要涉及闪电科技等附属。路径和所属参照 JAR 见 `upstream-uncovered.json`。

特别需要区分：闪电科技没有 `assets/ae2lt` 专属覆盖，但其通用侧栏按钮可以得到代码适配；它的很多屏幕布局实际位于 `assets/ae2/screens`。只统计命名空间或看到某个按钮变亮，都不能证明该附属已完整移植。

## 兼容性核对与仍需处理的内容

- JSON 和 PNG 解码检查没有发现格式错误；最终来源清单的文件哈希全部对应当前包内容。
- 在取得的 1.20.1 基准上叠加资源包，检查 2,585 个模型记录及 204 份有效动画元数据，未发现动画帧越界。本轮基准集合和旧报告不同，不以模型数量增减判断覆盖率。
- 模型扫描留下两条记录：AdvancedAE 流体桶依赖外部 Forge 父模型，扫描未载入 Forge 资源因此不能把它判为模型损坏；遗留安全终端物品模型指向不存在的 `security_station_off` 父模型，AE2 15.4.11 的方块定义已没有该安全终端。本次记录为旧资源遗留，不冒充已解析成功。
- 源包遗留 4 个含空格/大写等非法资源路径，完整路径在 `summary.json`。它们保留在文件清单中，不计为成功加载的游戏资源。
- 已有量子计算机世界材质和原包 GUI 设计与上游仍有差异；量子盔甲、驱动器元件灯、特殊总线和部分附属 GUI 需要结合低版模型/渲染器评估，不能仅按同名文件覆盖。
- 代码仍保留 1.20.1 的复选框几何、滚动条接口、槽位高亮、数量输入快捷逻辑和菜单协议；本轮没有把这些高版本交互功能整体加入旧版。复杂附属自绘页面同样不保证全部覆盖。
- 未启动 Minecraft 进行画面验收；未把 1.1.2 安装进用户实例。发布附件见本仓库 1.1.2 Release。

## 使用本地 1.1.2

同时替换适配模组 JAR 与资源包 ZIP，重启客户端。仅重载资源包不足以加载新的 Mixin。优先检查 ME 驱动器优先级页、无线终端垃圾桶/设置页、磁铁设置、样板模式页签以及关闭资源包后的回退。

English summary: all 4,988 pack files were inventoried, including reverse comparisons against upstream assets. This is a partial backport, not complete resource or GUI parity. Version 1.1.2 fixes back/priority tabs and wireless submenu positioning. Five legacy namespaces lack a verified modern reference, and custom addon interfaces retain documented differences. Builds, development/production Mixin transformations and archive checks passed; no in-game visual test was performed.
