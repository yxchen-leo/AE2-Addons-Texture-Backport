# 1.1.1 按钮与侧栏修正

需要同时更新适配模组和资源包到 1.1.1，并重启客户端。

## 修正

- 文字按钮对齐 AE2 1.21.1 的 `AE2Button`：普通文字 `#F2F2F2`、悬停 `#517497`、禁用 `#413F54`；取消文字阴影并对齐状态相关的垂直位置，保留透明度和长文本滚动。
- CPU 列表贴图左侧有 1 像素透明边，而高版本对应贴图从第 0 列开始绘制。因此将合成状态页的侧栏 `left` 从 `-85` 改为 `-84`，覆盖列表面板的明暗边框并衔接底色。
- 侧栏标记扩展到 `AbstractButton`，覆盖不继承 AE2 `IconButton` 的水晶科技控件。
- 在 `AbstractWidget.render()` 调用整个 `renderWidget()` 的范围内设置统一背景和绘制层级，保留虚调用。闪电科技在 `super.renderWidget()` 之后追加的状态图标，也会在背景上方绘制。
- 仅在上述作用域内跳过旧版 AE2 的 16×16 工具栏背景片段，保留附属自有图标、状态和点击逻辑。不注册到 AE2 工具栏、半尺寸或非 16×16 控件沿用原绘制。

## 分析依据

高版本源码：AE2 1.21.1 提交 `db17504a86128fdf3dae31f5fb7a112a646e0b93` 的 `AE2Button`。

实际安装的附属 JAR：`ae2lt-forge-1.20.1-2.1.2-beta2.jar`（闪电科技）和 `ae2cs-1.20.1-1.2.0.jar`（水晶科技）。静态检查了其独立按钮基类、纹理切换按钮、追加图标与背景绘制路径，未修改这两个 JAR，也没有增加附属模组的强制依赖。
