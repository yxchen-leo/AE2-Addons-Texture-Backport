# AE2 与附属模组浅色材质合并包 · Minecraft 1.20.1 Forge

当前资源包版本为 **v1.0.2**。成品在 `dist` 文件夹，需要配套安装以下两个文件；已经装好的按钮适配模组无需更新。

本轮已完成包内全部资源的静态清点，以及可取得的 1.21.1 JAR 对照，补入或校正 101 张 PNG、10 份动画继承配置和 12 个模型文件。**仍不能称为所有资源均与高版本完全一致**：剩余 18 张同路径方块/物品/部件图片有可见差异，另有 5 个资源命名空间未取得高版本参照。详细范围、保留原因和未验证项见 [核对报告-v1.0.2.md](核对报告-v1.0.2.md)。

| 文件 | 放置位置 | 用途 |
| --- | --- | --- |
| `AE2-Addons-Texture-Backport-1.20.1-v1.0.3.zip` | 当前游戏实例的 `resourcepacks` 文件夹 | GUI、方块和物品材质 |
| `AE2-Light-UI-Compat-Forge-1.20.1-1.0.2.jar` | 当前游戏实例的 `mods` 文件夹 | 只给 AE 注册的通用按钮换肤 |

配套模组现名为 **AE2 浅色界面适配（AE2 Light UI Compat）**。从旧名称版本换用本 JAR 时，请移除旧的 `AE2-Isolated-Light-Buttons-Forge-1.20.1-v1.0.0.jar`，两者只安装一个；现有资源包可继续使用。

## 安装

1. 关闭游戏，将 JAR 放进正在使用的 **Forge 1.20.1 实例**的 `mods` 文件夹。不要放入资源包文件夹。服务端无需安装。
2. 将资源包 ZIP 原样放入该实例的 `resourcepacks`，无需解压。
3. 启动游戏，在「选项 → 资源包」中启用这个合并包。
4. **停用旧版 v1.0.0/v1.0.1 和两个原资源包**（AE-Light-UI 和 AE2LightMode），也停用此前制作的 AE2 移植包。不要把它们放在合并包下面继续启用：本包主动省略的原版界面和量子核心模型会从下层资源包重新加载，使隔离或模型修复失效。
5. 若还在使用其他材质包，将本合并包置于它们上方。其他包本身对原版界面的修改仍会生效。

只装 ZIP 时，合并材质仍然可用，但 AE 的优先级加减等通用按钮保持原样。配套 JAR 和 ZIP 同时启用后，这些按钮使用专用浅色贴图，Minecraft 原版按钮不受影响。

## 合并内容

- AE2 和附属模组的 GUI、界面布局与主文字颜色以 **AE-Light-UI 3.6.0** 为基础，保留其深色文字。
- 量子计算机的 17 个贴图及动画元数据文件采用 **AE2LightMode 1.0.6** 的对应资源，包括成型后的紫色流光和核心动画。
- 去掉第一个包额外提供的量子计算机方块状态、核心模型、成型模型覆盖，让 **AdvancedAE 1.20.1 自带模型与渲染器**工作，与第二个包的处理方式一致。两个原包的核心 PNG 相同，仅换 PNG 无法解决模型覆盖的问题。
- **v1.0.1：**量子计算机结构玻璃的物品模型使用 AdvancedAE **1.6.11 / Minecraft 1.21.1** 的透明立方体模型。高版本贴图复制到独立物品路径，物品栏显示更新，但世界内方块与成型流光仍使用 v1.0.0 已有资源。
- **v1.0.1：**MEGA Cells 的累积处理器、电路板（printed accumulation processor）和压印模板使用 **MEGA Cells 4.11.0 / Minecraft 1.21.1 实际 JAR** 中的贴图及模型。已确认这三张高版本贴图与第一个原包一致，与第二个原包不同；v1.0.0 误将第二个包作为高版本基准，本版已纠正。
- 其他 AE2 和附属模组的方块、物品材质继续以第一个包为基础；补入第二个包的 FullEng 贴图及 Applied Flux 图集注册。
- **v1.0.2：**以实际高版本 JAR 校正 AE2、AE Additions、晶体科学、网络分析器、Applied Flux 等附属的一批图片，并补齐旧版模型实际引用而包中遗漏的 AdvancedAE、晶体科学和 ExtendedAE Plus 图片。此次 101 张 PNG 的来源与哈希均已记录，最终 ZIP 已逐张与来源 JAR 复核。
- 移除所有 Minecraft 原版 GUI 贴图覆盖，包括生存/创造物品栏、箱子、工作台、菜单及通用按钮；移除 JEI、背包、Botania、ProjectE 等非 AE 模组自身界面的覆盖。AE 的联动附属自身资源仍保留。
- 保留的唯一 `assets/minecraft` 文件是方块图集注册 `atlases/blocks.json`，用于 Applied Flux 的能量图标；它不会改变原版界面。
- 修正源包中 6 个静态图片的越界动画配置，以及 ExtendedAE 的熵化碎片纹理命名空间拼写错误。
- **v1.0.2：**另外阻止 AE2/MEGA 共 10 张静态存储灯图片继承旧版多帧元数据，并修复 12 个模型的未定义贴图变量；保留原有几何和 UV。

## 专用按钮的隔离方式

Minecraft 1.20.1 的 AE2 使用原版通用按钮绘制优先级、数量等控件。第一个原包通过覆盖全局 `minecraft:textures/gui/widgets.png` 换肤，因此会连带改变其他界面。

本包把那张图片移动到私有路径 `ae2lightuicompat:textures/gui/widgets.png`。配套模组仅标记 AE2 的 `WidgetContainer` 注册的按钮，在这些按钮沿用原版绘制方法时切换贴图和文字颜色。它不会修改全局贴图，不根据按钮上的“+1”文字猜测控件，也不会给整个屏幕里的所有按钮换肤。AE 专用图标按钮保留其原本的专用绘制。

附属模组通过 AE2 控件体系建立的界面会使用相同处理；完全自行实现绘制的控件不强行修改。停用合并资源包并重新加载后，小模组会自动恢复原按钮样式。

## 文件与复现

- `pack/AE2-Addons-Texture-Backport-1.20.1-v1.0.3/`：可直接查看或继续编辑的解压版；旧版文件保留便于回退。
- `核对报告-v1.0.2.md`、`inspection/full-audit/`：完整逐模组报告、逐文件对照和剩余差异清单。
- `sources/audit-fixes/`：本轮 101 张上游图片的固定快照与来源哈希。
- `sources/items-1.21.1/`：此次修正使用的实际高版本资源快照、来源 JAR 哈希与逐文件哈希。
- `file-provenance.json`：每个资源的来源与 SHA-256。
- `validation-pack.json`、`validation-mod.json`：检查报告和成品哈希。
- `inspection/source-comparison.png`：原包材质对照图，仅为贴图检查图，不是游戏截图。
- `companion/src/main/`：客户端适配模组源码；`companion/src/test/`：离线 Mixin 验证代码，不打入成品 JAR。
- 在项目根目录运行 `python AE2-Combined-1.20.1/build_pack.py`、`python AE2-Combined-1.20.1/verify_pack.py`、`python AE2-Combined-1.20.1/verify_item_fixes.py` 可重建和检查资源包。
- 运行 `verify_audit_fixes.py` 可再次与来源 JAR 核对本轮图片；运行 `audit_compatibility.py` 可检查已下载的 1.20.1 基准与包叠加后的模型和动画。两者均为静态验证，不会启动游戏。
- 运行 `build_mod.py` 和 `verify_mod.py` 可重建/验证适配模组。构建依赖保存在 `tools/forge-client`，由官方 Forge 安装器准备；脚本直接使用 Forge 1.20.1 的 SRG 运行时名称，不需要额外混淆步骤。JDK 路径可通过 `AE2_BUILD_JAVA_HOME` 指定。

两个原包保持不变。原资源署名及许可见 `CREDITS.txt`；适配代码使用独立 MIT 许可。此合并包未获原模组作者背书。

升级配套要求：资源包 1.0.3 与适配模组 1.0.2 配套使用。内部 ID 已更改，安装前必须删除所有旧版适配模组 JAR，否则旧 ID 不会触发重复模组检测，可能同时加载两套注入。
